# ARION 3.4 — Mustaqil agent yadrosi

Bu tarmoq ARION 3.3 multi-AI fallback asosida ochildi; mavjud UI va ovoz kodi alohida saqlangan.

## Kiritilgan poydevor
- Vazifa holatlari: tasdiq kutmoqda, tayyor, bajarilmoqda, bajarildi, xato, bekor qilindi.
- Harakat turlari: izlanish, xabar qoralamasi, xabar yuborish, buyurtma qoralamasi, demo savdo, real savdo, pul o'tkazish, shartnoma va kod o'zgartirish.
- Siyosat darvozasi: izlanish va qoralama avtomatik; tashqi ta'sir qiluvchi amallar tasdiq talab qiladi.
- Hisob-kitob: pul miqdori Float/Double emas, eng kichik birlikdagi Long bilan yuritiladi.
- Real savdo va pul o'tkazish sukut bo'yicha o'chirilgan; avtomatik sarf limiti 0.

## Hozircha nima EMAS
Bu hali to'liq mustaqil xizmat yoki real kripto bot emas. Hozircha birinchi Kotlin yadro sinfi: Android UI, serverdagi 24/7 ishchi, xavfsiz saqlanadigan uzoq muddatli vazifa ombori va birja adapteri hali ulanmagan. Build o'tishi va qurilmada tekshirilishi shart.

## Keyingi bosqich
1. Yadroni UI dagi Agent rejimiga ulash va vazifalar ro'yxatini ko'rsatish.
2. Serverda doimiy navbat, qayta urinish, monitoring va audit jurnalini qo'shish.
3. Kripto uchun avval faqat tarixiy/backtest va paper trading; keyin litsenziyalangan provayder adapteri, alohida limitlar va qo'lda tasdiq.
4. Xabar yuborish va buyurtma topshirish kabi vakillik harakatlariga foydalanuvchi belgilagan doira va bekor qilish imkonini qo'shish.

Hech qachon seed phrase, parol, API kalit yoki bank PIN kodini model promptiga yubormang.
